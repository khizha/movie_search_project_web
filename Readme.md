# Movie Search Project

Веб-приложение для поиска фильмов в базе данных MySQL с сохранением истории поисковых запросов и формированием статистики в MongoDB.

### Описание проекта
Приложение предоставляет веб-интерфейс для поиска фильмов и просмотра статистики поисковых запросов.

### Функциональные возможности:
* поиск фильмов по ключевому слову;
* поиск фильмов по жанру и диапазону годов выпуска;
* просмотр результатов поиска с пагинацией по 10 фильмов;
* сохраннение истории выполненных поисковых запросов;
* просмотр 5 наиболее популярных запросов;
* просмотр 5 последних уникальных запросов.

### Используемые технологии
* Python 3.13 - основной язык программирования.
* MySQL - реляционная база данных для хранения данных о фильмах и выполнения поисковых запросов.
* MongoDB - нереляционная база данных для хранения истории поисковых запросов и получения статистики.
* mysql-connector-python -  Python-пакет для взаимодействия с MySQL.
* pymongo - Python-пакет для взаимодействия с MongoDB.
* Flask - Python-фреймворк для создания веб-приложений.
* pytest - фреймворк для автоматического тестирования Python-кода.

### Архитектура приложения

Основная логика разделена между Flask-маршрутами, сервисным модулем поиска и модулями работы с базами данных.

#### Схема взаимодействия:
```text
Пользователь
    │
    ▼
Flask (app.py)
    │
    ├── поиск фильмов ──► search_service.py
    │                         │
    │                         ▼
    │                  mysql_connector.py
    │                         │
    │                         ▼
    │                       MySQL
    │
    └── история и статистика ──► mongo_logger.py
                                   │
                                   ▼
                                MongoDB
```                                

* app.py - отвечает за HTTP-маршруты, получение данных из форм, проверку пользовательского ввода, пагинацию и передачу
* данных в HTML-шаблоны.
* search_service.py - содержит функции поиска и обращается к функциям из mysql_connector.py.
* mysql_connector.py - отвечает за подключение к MySQL и выполнение SQL-запросов.
* mongo_logger.py - отвечает за подключение к MongoDB, сохранение истории и получение статистики.
* formatters.py - преобразует данные из MongoDB в строки, удобные для вывода на страницах статистики.
* logger.py - настраивает запись ошибок приложения в файл.

#### Маршруты Flask
```  
Маршрут         Назначение
/               Главная страница
/search         Поиск фильмов по ключевому слову
/genre          Поиск по жанру и диапазону годов
/popular        Популярные поисковые запросы
/recent         Последние уникальные поисковые запросы
```

### Использование баз данных

В проекте используются две базы данных: MySQL и MongoDB.
- **MySQL (база данных sakila)** — хранение данных о фильмах и выполнение поисковых запросов.
- **MongoDB** — хранение истории поисковых запросов и получение статистики.

Каждый выполненный поисковый запрос сохраняется в MongoDB в виде документа со следующими полями:

- `search_type` — тип поиска;
- `search_params` — параметры поискового запроса;
- `results_count` — количество найденных фильмов;
- `created_at` — дата и время выполнения запроса.

Пример документа:

```json
{
    "search_type": "keyword",
    "search_params": {
        "keyword": "dinosaur"
    },
    "results_count": 12,
    "created_at": "..."
}
```
### Особенности реализации
- Предусмотрена обработка некорректного пользовательского ввода.
- Для анализа ошибок доступа к базам данных используется запись информации в лог-файл.
- Реализованы автоматические тесты с использованием pytest.
- Для отдельных модулей предусмотрены smoke-тесты для проверки их базовой работоспособности.
- Для вывода результатов поиска используется пагинация.
- Чувствительные данные для подключения к базам данных хранятся в локальном файле настроек и не включаются в репозиторий.

### Тестирование
Для автоматического тестирования проекта используется `pytest`.

#### Модульные тесты
Проверяют работу отдельных функций проекта:
- форматирование данных;
- поиск фильмов по ключевому слову;
- поиск фильмов по жанру и диапазону лет;
- получение количества найденных фильмов;
- получение списка жанров с диапазонами лет;
- получение популярных и последних уникальных запросов.

#### Интеграционные тесты
Проверяют взаимодействие приложения с внешними компонентами:
- подключение к MySQL;
- подключение к MongoDB;
- работу Flask-маршрутов основных страниц;
- обработку некорректного пользовательского ввода.

Для отдельных модулей предусмотрены smoke-тесты, позволяющие проверить их базовую работоспособность при непосредственном запуске.

### Конфигурация и запуск проекта

#### Установить зависимости:
```bash
pip install -r requirements.txt
```
Перед запуском необходимо указать параметры подключения к MySQL и MongoDB в локальном файле настроек.

#### Запустить приложение:
```bash
python app.py
```
После запуска Flask-сервер будет доступен по адресу:
[http://127.0.0.1:5000](http://127.0.0.1:5000)
